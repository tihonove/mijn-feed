# Mijn Feed — персональная лента

Личный «тикток»: вертикальная лента карточек. Голландский (слова, грамматика) с повторами как в Anki,
плюс другие потоки (новости, факты) для разбавления. Один пользователь, вход через Google,
приложение ставится на телефон как PWA. Крутится в кластере `tihonove.dev`.

## Принципы

- **Снаружи стабильно, внутри свободно.** Публичный API (то, чем пользуется приложение на телефоне
  и производители контента) версионирован (`/v1`) и меняется только добавлением. Всё за ним —
  планировщик, схема базы, способ рендера — можно переделывать.
- **Карточка это свободный HTML.** Платформа не навязывает шаблоны. Шаблоны и заготовки живут
  у производителя контента (его «поваренная книга»). Карточка рендерится в изолированном iframe
  и общается с оболочкой узким протоколом.
- **Повторы это отдельная система** (колода `nl`, устройство как в Anki, планировщик FSRS).
  Лента про повторы не знает: она спрашивает у колоды «что показать сейчас» и возвращает оценки.
- **Повторяется грань заметки, а не картинка.** У одной грани несколько подач; при повторе
  берётся ещё не виденная. Нет подач — простая встроенная, а производителю задача на свежую.
- **Крутилки доступны снаружи.** Доли потоков и настройки колоды — ресурс API, одинаковый
  для экрана настроек в приложении и для скриптов/агентов.

## Сущности

```
stream      поток: nl | news | facts | …      ← доли и быстрые режимы
  ├ nl: колода
  │   note        заметка: слово / грамматическая тема; поля, теги, уровень
  │   facet       грань заметки = карточка Anki: nl→ru, ru→nl, на слух, применить, собрать…
  │               у грани состояние планировщика (FSRS) и журнал повторов
  │   presentation подача грани: HTML + звук + файлы; несколько на грань
  └ прочие потоки: item — разовая карточка с html, сроком жизни, источником
```

## Публичный API `/v1` (стабильная часть)

Зритель (cookie‑сессия после входа через Google):

| Метод     | Путь                   | Что                                                                                     |
| --------- | ---------------------- | --------------------------------------------------------------------------------------- |
| GET       | `/v1/feed?limit=20`    | плейлист: `[{id, stream, kind, html, audio, meta}]` — уже смешанный по долям и правилам |
| POST      | `/v1/feed/{id}/events` | `{type: seen \| grade \| skip \| boring, grade?: again \| hard \| good \| easy}`        |
| GET / PUT | `/v1/settings`         | доли потоков, быстрые режимы, настройки колоды                                          |
| GET       | `/v1/stats`            | к повтору сегодня, прогноз, удержание, зрелые/молодые                                   |
| GET       | `/v1/me`               | кто вошёл                                                                               |

Производитель (bearer‑токен):

| Метод     | Путь                               | Что                                                                       |
| --------- | ---------------------------------- | ------------------------------------------------------------------------- |
| GET       | `/v1/nl/state`                     | что скоро к повтору и сколько у них подач, покрытие тегов, последние виды |
| POST      | `/v1/nl/notes`                     | заметка + грани + подачи одним пакетом                                    |
| POST      | `/v1/nl/facets/{id}/presentations` | новая подача к старой грани                                               |
| POST      | `/v1/streams/{stream}/items`       | разовые карточки (новости, факты)                                         |
| POST      | `/v1/media`                        | загрузка mp3/картинок, в ответ URL                                        |
| GET / PUT | `/v1/settings`                     | те же крутилки снаружи                                                    |

## Протокол карточки (внутри iframe, версия 1)

Оболочка → карточка: `{type:"active"}` / `{type:"inactive"}` (запускать и останавливать анимации),
`{type:"theme", tokens}`.
Карточка → оболочка: `{type:"ready"}`, `{type:"play", src?, text?, auto?}` (звук играет оболочка: файл карточки,
другой файл или произнести `text`; `auto` — просьба не по нажатию, оболочка выполняет её только при включённом звуке;
повтор той же просьбы в пределах секунды игнорируется),
`{type:"answer", correct:boolean}` (квиз сам ставит оценку), `{type:"reveal"}`.
Оболочка подмешивает базовые стили и шрифты; сеть из карточки закрыта, кроме `/media`.

## Колода `nl`: крутилки

желаемое удержание (FSRS, по умолчанию 0.9) · новых в день · потолок повторов в день ·
шаги обучения (1м, 10м) и переобучения · максимальный интервал · порядок новых ·
прятать грани одной заметки в один день · порог «пиявки».

Оценки на ленте: две кнопки «снова» / «хорошо», долгое нажатие даёт «трудно» / «легко».

**Лента не кончается.** «Новых в день» и «потолок повторов» — норма, а не потолок: когда очередь по норме пуста,
сервер ставит служебную карточку «норма сделана» и продолжает «сверх нормы»: новые сверх лимита, затем всё
запланированное по возрастанию срока (досрочный повтор FSRS учитывает честно), без прятания граней одной заметки.
Оценки сверх нормы — обычные оценки. Остановиться — решение человека, не планировщика (решено 2026‑10‑31).

## Лента: крутилки

доли потоков (например 60/25/15) · «не больше N подряд одного потока» · быстрые режимы на день
(«только голландский», «без новостей») · свежесть новостей · позже «скучно» снижает вес тегов.

## PWA и оболочка ленты

Манифест, standalone, иконка; service worker кеширует оболочку, последний плейлист и его звук,
оценки в офлайне копятся и досылаются.

- **Память.** В DOM живут только iframe текущей карточки и соседей (одна назад, две вперёд);
  остальные — пустые заглушки той же высоты. Ушёл дальше — iframe выгружается, подошёл — загружается заранее.
- **Панель реакций общая**, у оболочки, а не у карточки: звук, «снова»/«хорошо» (долгое нажатие — «трудно»/«легко»),
  «скучно», «ещё такого». Карточка может только сообщить результат квиза.
- **Реакции учитываются.** Оценки идут в планировщик; «скучно»/«ещё такого» двигают веса потока и тегов в микшере.
- **Звук как в Instagram.** Один глобальный переключатель: включил — играет на каждой карточке при появлении,
  выключил — везде тихо. Состояние помнится. Отдельная кнопка «переозвучить» проигрывает заново.

## Аутентификация

Google OAuth, права только `openid email profile` (проверка приложения Google не нужна).
Список разрешённых email в настройках сервера. Для разработки — dev‑вход без Google.
Производители ходят с bearer‑токеном.
